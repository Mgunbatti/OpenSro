# GM-023: a failed IP statistics query is never answered

- Original: `DB_IPStatistics` (0x45d3b0, CGlobalManagerSlave, 0x6319 detail 16), GlobalManager
- Rewrite: `CGlobalManagerSlave::IPStatistics` in
  `JMX_CommonServers/GlobalManager/GlobalManagerSlave.cpp`
- Severity: low

## What the original does

The 0xA319 answer is allocated before the query. When `exec _IPStatistics` fails the error
answer {0x19, request, 0x1B} is written into it and the function returns; only the success
branch puts the message into the main task's queue.

## Effect

The requester gets no answer for a failed query, and the message is lost from the pool (one per
failure).

## Fix

Put the error answer into the main task's queue as well.
