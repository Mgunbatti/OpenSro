# GM-008: the answer to 0x7410 has the opcode of 0x7409

- Original: `COverlapJob_QueryUserByUserID` setup (sub_427C10) and vf08 (0x427e00), GlobalManager
- Rewrite: `OverlapJob_SetupQueryUserByUserID` / `COverlapJob_QueryUserByUserID::OnFail` in
  `JMX_CommonServers/GlobalManager/ServiceManagerJobs.cpp`
- Severity: low

## What the original does

The account query by user ID (0x7410) builds its massive answer with opcode 0xB409, the opcode of
the character owner query (0x7409, COverlapJob_QueryCharOwnedUser). Every other SMC request is
answered with its own opcode + 0x4000.

## Effect

The SMC gets the result of 0x7410 as an answer to 0x7409 (the rows have the same 194-byte layout, so
it may even display it there).

## Fix

Use 0xB410.
