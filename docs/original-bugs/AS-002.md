# AS-002: a session ID 0 stops the multi-session relay

- Original: `CAgentMainProcess::OnMsg_220A` (0x4037f0), AgentServer
- Rewrite: `CAgentMainProcess::OnMsg_220A` in `JMX_CommonServers/AgentServer/AgentMainProcess.cpp`
- Severity: low

## What the original does

0x220A carries the target sessions as a DWORD list before its WORD count and WORD opcode; the
handler walks the list from its end. Only the branch that sends the message moves the pointer to the
previous entry; for a session ID 0 it logs "there is invalid session id at relay msg (multi list)"
and keeps the pointer.

## Effect

After the first 0 in the list every remaining iteration reads the same 0 again: the rest of the
sessions get nothing and the line is logged once per remaining entry.

## Fix

Move the pointer in both branches.
