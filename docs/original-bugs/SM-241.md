# SM-241: The master's party matching notice names the requester

- Original: `CPartyManager::OnPartyMatchJoinAnswer` (0x44fbe0), SR_ShardManager
- Rewrite: `CPartyManager::OnPartyMatchJoinAnswer` in `SilkroadOnline/Server/ShardManager/PartyManager.cpp`
- Severity: minor

## What the original does

When the master of a party matching entry accepts a request and has no party yet, a new party is
created and both users get a 0x3864 subtype 17 notice. Both notices are written with the
requester's JID; the one sent to the master's session should carry the master's JID (the path
that adds the requester to an existing party does so).

## Effect

The game server of the master receives a result addressed to the requester's JID.

## Fix

Write the master's JID into the master's notice.
