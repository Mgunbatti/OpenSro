# DB-008: DescribeColumns leaks the statement for a table without columns

- Original: `CDBTable::DescribeColumns` (0x478e40), GatewayServer
- Rewrite: `CDBTable::DescribeColumns` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: minor

## What the original does

After binding the `SQLColumns` result the function fetches the first row and returns 0 at
once when the bound column name is empty, which is the case when `SQLColumns` found no column
(wrong table name, missing table). The same check follows every later fetch. These returns skip
the `SQLFreeStmt` / `SQLFreeHandle` at the end of the function.

## Effect

Every failed table open leaks one statement handle on connection 0 of the pool.

## Fix

Leave through the common cleanup.
