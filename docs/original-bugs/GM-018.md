# GM-018: billing answers for unknown users leak the reply message

- Original: `CStandardBillingMgr::vf10` (0x4524f0, 0x4002) and `CStandardBillingMgr::vf14`
  (0x452940, 0x4006), GlobalManager
- Rewrite: `CStandardBillingMgr::OnLoginAck` and `CStandardBillingMgr::On4006` in
  `JMX_CommonServers/GlobalManager/Billing/StandardBillingMgr.cpp`
- Severity: low

## What the original does

Both handlers allocate the reply (0xA201 / 0xA900) from the engine's message pool before they
look the user up. When the user is not logged in any more they log the CP949 text "user data
missing" and return without releasing the message.

## Effect

Every billing answer for a user who already left takes one message from the pool for good.

## Fix

Look the user up first, or release the message on that path.
