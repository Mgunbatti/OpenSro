# SM-013: The "can't find MagicOptGroup" message passes a std::string to %s

- Original: `RefMagicOptGroup::Read` (0x492360), SR_ShardManager
- Rewrite: `RefRow_Read(CRefRow&, RefMagicOptGroupRow&)` in `SilkroadOnline/Server/ServerCommon/ReferenceData.cpp`
- Severity: minor

## What the original does

When a _RefMagicOptGroup row names a magic option that is not in _RefMagicOpt, the reader shows
"can't find MagicOptGroup[%s]:MagicOptLevel[%d] ...". It copies the 28-byte `std::string` of the
code name onto the stack as the argument for `%s` (`rep movsd`), followed by the MLevel byte. The
`%s` therefore reads the string object's first DWORD as a pointer and `%d` its first characters.

## Effect

The message box shows garbage or the formatting faults on an invalid pointer, right when the
data is wrong. The rewrite passes the characters and the MLevel instead (the original output
cannot be reproduced).

## Fix

Pass `c_str()` and the MLevel.
