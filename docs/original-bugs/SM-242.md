# SM-242: A failed accepted party matching join keeps the entry locked

- Original: `CPartyManager::OnPartyMatchJoinAnswer` (0x44fbe0), SR_ShardManager
- Rewrite: `CPartyManager::OnPartyMatchJoinAnswer` in `SilkroadOnline/Server/ShardManager/PartyManager.cpp`
- Severity: minor

## What the original does

`OnPartyMatchJoinRequest` sets the entry's join-pending flag (+0x34) before asking the master.
The refusal and timeout answers clear it, and so does a successful accept. When an accepted
answer fails (the master's party is gone, `AddMember` or `CreateParty` fails) the error notices
are sent and the function returns without clearing the flag.

## Effect

Every further join request for that entry is answered with 0x2C1F (join pending) until the entry
is removed or re-registered.

## Fix

Clear `m_bJoinPending` on every return path once the entry was found.
