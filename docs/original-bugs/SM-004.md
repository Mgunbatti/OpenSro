# SM-004: Resetting a server event reward does not mark RewardID for the update

- Original: `CInstanceServerEventReward::InitData` (0x525ba0), SR_ShardManager
- Rewrite: `CInstanceServerEventReward::InitData` in
  `SilkroadOnline/Server/ServerCommon/InstanceRecords.cpp`
- Severity: minor

## What the original does

`_ServerEventReward.RewardID` is in update group 2, but InitData sets it to 0 without dirty
bit 2, while `RemainRewardTime` of the same group does set it.

## Effect

When only RewardID was non-zero, the reset record has no dirty group and the next update does
not write the zero; otherwise the zero is written together with RemainRewardTime.

## Fix

Set dirty bit 2 when RewardID is reset.
