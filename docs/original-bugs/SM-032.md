# SM-032: A drop item of a country above 3 is added past the drop class tables

- Original: `DropClassTable_AddItem` (0x51dda0), SR_ShardManager
- Rewrite: `RefDropClassSlot_AddItem` in `SilkroadOnline/Server/ServerCommon/RefDataDrop.cpp`
- Severity: minor

## What the original does

The country byte of the item (_RefObjCommon +0x88) selects one of the three entry vectors of a
drop class, 3 meaning all three. A value above 3 is only asserted; the vector is then taken at
16 * country bytes into the class, past its three vectors (the next class or the next member).

## Effect

An item with a bad country value corrupts or crashes the drop class build instead of being
rejected.

## Fix

Skip the item (and log it) when the country is above 3.
