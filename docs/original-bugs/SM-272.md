# SM-272: Party matching list rebuild leaks a page message

- Original: `CPartyManager::RebuildMatchListCache` (0x451630), SR_ShardManager
- Rewrite: `CPartyManager::RebuildMatchListCache` in `SilkroadOnline/Server/ShardManager/PartyManager.cpp`
- Severity: minor

## What the original does

A page message is allocated whenever the count of written entries of the current page is 0.
When the entry written into a fresh page fails and further entries follow, the next iteration
allocates another message and the first one is neither stored nor released.

## Effect

One message of the network engine's pool leaks per failed entry at the start of a page.

## Fix

Allocate the page only when no page is open.
