# DB-012: Bound fetch loops never end on a fetch error

- Original: `CDBTable::BulkFetchBoundRows_A` (0x477050) and `_B` (0x477460), GatewayServer
- Rewrite: `CDBTable::FetchBoundByOrdinal` and `FetchBoundSequential` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: crash

## What the original does

The rowset loop calls `SQLFetchScroll(h, SQL_FETCH_NEXT, 0)` until it returns
`SQL_NO_DATA`. Other results are not checked.

## Effect

When `SQLFetchScroll` fails (connection lost, conversion error, invalid cursor state) it
keeps returning `SQL_ERROR`; the loop handles the rows-fetched count of the last call over and
over (creating records again when it is not 0) and never ends.

## Fix

Leave the loop on any result other than `SQL_SUCCESS` / `SQL_SUCCESS_WITH_INFO` and report
the error.
