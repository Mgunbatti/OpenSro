# SM-200: A guild level-up whose master is offline is answered as a failure

- Original: `CGuildManager::OnLevelUpGuild` (0x438bb0), SR_ShardManager
- Rewrite: `CGuildManager::OnLevelUpGuild` in `SilkroadOnline/Server/ShardManager/Guild.cpp`
- Severity: minor

## What the original does

Subtype 9 of 0x78F7 levels the guild up (`CGuild::LevelUp`, record saved), tells the game
servers (`SendLevelUpResult`) and then looks up the master's user by the master record's
character name to write the GP history entry. When the guild has no master record, or the master
is not logged in, it asserts and answers the request with 0xB8F7 {request ID, 2, WORD 1}: the
error form with the success code as error.

## Effect

The level-up has happened in the DB and on the game servers, but the requesting game server is
told it failed (error code 1), and no GP history entry is written for the spent GP. The
requester is usually the master himself, so the case needs a master record mismatch or a
logout race.

## Fix

Write the GP history with the JID of the requesting character (or skip it) and answer with the
success form {1} once the level-up is stored.
