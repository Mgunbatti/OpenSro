# SM-051: A teleport link out of service leaks

- Original: `CRefInstanceGenerator::LoadTeleLink` (0x4a41f0), SR_ShardManager
- Rewrite: `RefData_LoadTeleLink` in `SilkroadOnline/Server/ServerCommon/RefDataTeleport.cpp`
- Severity: minor

## What the original does

The loader allocates the 28-byte link (with room for five restrictions) before it reads the
row. `RefTeleLink::Read` (0x4930f0) returns 0 for a row whose Service column is 0, and the
loader then returns without storing or freeing the link.

## Effect

Every `_RefTeleLink` row out of service leaks one link object and its restriction buffer once
per start-up.

## Fix

Free the link when the reader returns 0.
