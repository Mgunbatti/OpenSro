# GM-019: a billing string that has to be cut throws

- Original: `sub_451D80` / `sub_451DF0` (billing packet strings) and the inlined copy in
  `CStandardBillingMgr::vf19` (0x453770), GlobalManager
- Rewrite: `CBillingPacket::WriteString` in
  `JMX_CommonServers/GlobalManager/Billing/BaseBillingMgr.cpp`
- Severity: low

## What the original does

A string is written as WORD length and text. When length and position reach 4096 the length is
cut to `4095 - position`, computed before the length word is written; the text then ends at byte
4097 and the write throws an int.

## Effect

Instead of a cut string the handler (on the billing worker thread) throws an exception nobody
catches, which ends the process. The strings are short (MAC addresses, the account's MAC in the
login), so a packet only gets there with a very long text.

## Fix

Count the length word when cutting (`4093 - position`).
