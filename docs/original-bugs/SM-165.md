# SM-165: Party and guild level lists are not cleared before the team building

- Original: `CBattleArenaMgr::StartGameParty` (0x672d40) and `CBattleArenaMgr::StartGameGuild`
  (0x673730), SR_ShardManager
- Rewrite: `CBattleArenaMgr::StartGameGroup` in
  `SilkroadOnline/Server/ShardManager/BattleArena.cpp`
- Severity: minor

## What the original does

The team building appends one {party / guild, highest level} entry per group of the level map
(`+0x1C0` / `+0x274`) to the member list `+0x1E4` / `+0x298` and sorts it. The list is only
cleared at the end of the game (`OnScheduledGameEnd`, `OnGameEnded`), not before it is filled.

## Effect

When the game of a match type is started a second time in the same period (a GM CheckAndGo, or
a second schedule run), every group appears twice in the list. Groups are paired with themselves
or teamed up again, members get a second 0x34D2 type 1, and more layers are opened than needed.

## Fix

Clear the list before filling it.
