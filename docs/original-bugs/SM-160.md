# SM-160: Siege fortress relay broadcasts the received message and leaks the relay

- Original: `CSiegeFortressMgr::OnMsg_385F` (0x668e80), SR_ShardManager
- Rewrite: `CSiegeFortressMgr::OnMsg_385F` in `SilkroadOnline/Server/ShardManager/SiegeFortress.cpp`
- Severity: minor

## What the original does

For the types 7 and 12/13 the handler reads the fields of the 0x385F message, builds a new
0x385F message with them and then passes the received message, not the new one, to
`CMainProcess::BroadcastToGameServers`. The new message is never sent nor released. Type 8 sends
its new message as intended.

## Effect

The game servers get the original message (with the same fields, so the content is the same),
and every such message costs one message of the pool. The rewrite does the same.

## Fix

Broadcast the new message.
