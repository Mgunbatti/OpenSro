# SM-276: A failed camp disband removes the members from the character map

- Original: `CTrainingCampManager::DeleteCamp` (0x4574c0), SR_ShardManager
- Rewrite: `CTrainingCampManager::DeleteCamp` in `SilkroadOnline/Server/ShardManager/TrainingCamp.cpp`
- Severity: minor

## What the original does

Before `DBDeleteCamp` runs `_TRAINING_CAMP_DELCAMP`, every member of the camp is erased from
the character-to-camp map (+0x98). When the procedure fails the camp and its members stay, but
the map entries are gone.

## Effect

`TrainingCampMgr_FindCampByChar` no longer finds the camp of these characters (lobby info,
camp ID of a character, 0x380E) until the camps are reloaded.

## Fix

Erase the map entries only after the DB delete succeeded.
