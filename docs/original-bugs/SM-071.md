# SM-071: A gacha free parameter with '<' but no '>' never finishes parsing

- Original: `CGachaFreeParam::Parse` (0x48ce90), SR_ShardManager
- Rewrite: `CGachaFreeParam::Parse` in `SilkroadOnline/Server/ServerCommon/RefDataMisc.cpp`
- Severity: major (with broken data only)

## What the original does

For a DescN column of _RefGachaItemSet that contains "[BIIV]", the parser looks for each '<',
then for the '>' after it, parses the text between them and searches the next '<' from the
position after the '>'. When there is no '>', that position is npos + 1 = 0, so the search finds
the first '<' again.

## Effect

The loop never ends: every round appends another entry (and asserts once the entry count reaches
five), until memory runs out while the reference data is built. The rewrite keeps the loop.

## Fix

Stop when there is no '>' after the '<'.
