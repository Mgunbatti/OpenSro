# SM-103: Instance worlds with WorldMaxCount 0 cannot open a layer

- Original: `CGameWorld::CreateLayer` (0x658b50), SR_ShardManager
- Rewrite: `CGameWorld::CreateLayer` in `SilkroadOnline/Server/ShardManager/GameWorld.cpp`
- Severity: minor (with such data only)

## What the original does

The layer slot vector has WorldMaxCount + 1 entries. For WorldMaxCount 0 (meant as "no limit")
CreateLayer makes a new layer with the ID size + 1 = 2, moves it from the free list and then
indexes the slot vector with vector::at, which throws std::out_of_range.

## Effect

Opening a layer of such a world throws out of the request handler; the new layer is leaked. The
rewrite does the same.

## Fix

Grow the slot vector before storing a layer beyond its end.
