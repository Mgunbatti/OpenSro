# GW-004: account database password written to the log

- Original: `CGatewayServer::InitDBAndModuleVersions` (0x403da0, vtable slot 11), GatewayServer
- Rewrite: `CGatewayServer::OnLocalDataInitialized` in `JMX_CommonServers/GatewayServer/GatewayServer.cpp`
- Severity: medium (information disclosure)

## What the original does

In division 2 the account database connection string is Server.cfg "AccountDBConfig" with a
password compiled into the binary inserted after "PWD=". When the connection fails, the complete
string is logged with "cannot connect to account DB : %s" at level 0x2000000.

## Effect

The built-in password ends up in the server window, the report log files and every other log
receiver. (The rewrite does not contain the original password; it is supplied at build time as
`GATEWAY_ACCOUNT_DB_PASSWORD`.)

## Fix

Log the configured string (without the inserted password) or only the data source.
