# NET-001: Initialize starts Winsock with the previous parameter block

- Original: `CNetEngine::Initialize` 0x480670 (GatewayServer)
- Rewrite: `CNetEngine::Initialize` in `JMX_Library/BSNet/NetEngine.cpp`
- Severity: minor

## What the original does

The first thing `Initialize` does is `NetIO_InitAndLoadAcceptEx` with the two Winsock version
bytes read from the engine's own copy of the parameter block (`this+9`, `this+0xA`). Only after
that it copies the 148-byte block it was given over that copy.

## Effect

The version bytes of the block passed to `Initialize` (`BSNET_INIT_PARAM::bWinsockLow/High`) are
never used for the first call; Winsock is always started with the constructor defaults (2.2).
Callers that ask for another version get 2.2 without notice.

## Fix

Read the version from the parameter, or copy the block before starting Winsock.
