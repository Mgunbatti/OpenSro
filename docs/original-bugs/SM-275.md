# SM-275: Training camp honor points are cut to one byte

- Original: `CTrainingCamp::RefreshMemberStatus` (0x456470), SR_ShardManager
- Rewrite: `CTrainingCamp::RefreshMemberStatus` in `SilkroadOnline/Server/ShardManager/TrainingCamp.cpp`
- Severity: minor

## What the original does

Status type 3 stores the honor points of a member: the value is zero-extended from its low byte
(`movzx ecx, byte [ebp+0x10]`) before it goes to the HonorPoint column of the member record.
The 0x3C80 subtype 5 notice sent afterwards carries the full DWORD.

## Effect

The shard's copy of a member's honor points is the value modulo 256; the next update of the
record (group 3) writes that value to the database, and the game servers see another value
than the shard.

## Fix

Store the whole value.
