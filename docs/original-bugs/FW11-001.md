# FW11-001: the UTF-8 helpers never return on an invalid lead byte

- Original: `UTF8_GetCharCount` (0x475a50), `UTF8_GetCharStartBefore` (0x475b70) and
  `UTF8_TruncateToWidth` (0x475e50), AgentServer (2011 library)
- Rewrite: `JMX_Library/BSLib/Util/StringUtil.cpp`
- Severity: low (the functions are not called in AgentServer)

## What the original does

The loops advance the string iterator by `UTF8_GetCharLength` of the current byte. For a byte
that is not a valid lead byte (0x80..0xBF, 0xF8..0xFF) the length is 0, so the iterator does not
move and the loop runs forever. `UTF8_GetDisplayWidth` stops at such a byte instead.

## Effect

Any string with a stray continuation byte or an invalid byte hangs the calling thread.

## Fix

Treat a length of 0 as one byte (or stop, like `UTF8_GetDisplayWidth`).
