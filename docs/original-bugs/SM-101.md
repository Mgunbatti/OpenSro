# SM-101: Rain and snow amounts wrap instead of being held at 255

- Original: `CClimate::RollWeather` (0x656c80), SR_ShardManager
- Rewrite: `CClimate::RollWeather` in `SilkroadOnline/Server/ShardManager/Climate.cpp`
- Severity: cosmetic

## What the original does

The target amount of a snow or rain roll is `Snowfall + rand() % (SnowfallVariance + 1)`
(Rainfall / RainfallVariance for rain), added in a BYTE. The code then compares the BYTE with
255 to hold it there, which can never change anything because the sum has already wrapped.

## Effect

With a base value and variance that add up to more than 255 the target amount comes out small
(for example 250 + 9 gives 3), so heavy rain or snow turns into a light one. The rewrite does
the same.

## Fix

Add in an int and clamp to 255 before storing the BYTE.
