# SM-042: A structure is added to its region twice

- Original: `RefObj_AddUniqueLinkedID` (0x4a0450), SR_ShardManager
- Rewrite: `RefObj_AddUniqueLinkedID` in `SilkroadOnline/Server/ServerCommon/RefDataObj.cpp`
- Severity: minor

## What the original does

The structure object is looked up in the structure list of its region; when it is already there
the function asserts and still appends it.

## Effect

Only reachable when the same object is read twice; the region then lists the structure twice.

## Fix

Return after the assert when the object is already in the list.
