# SM-003: COS owner changes are never marked for the database update

- Original: `CInstanceCOS::InitData` (0x522d20) and `CInstanceCOS::CopyTo` (0x522ee0),
  SR_ShardManager
- Rewrite: `CInstanceCOS::InitData` / `CopyTo` in
  `SilkroadOnline/Server/ServerCommon/InstanceRecords.cpp`
- Severity: minor

## What the original does

`_CHARCOS.OwnerCharID` is declared in update group 3 of the table description, but the
setter the record uses for it stores the new value without setting dirty bit 3 (every other
column of the record sets the bit of its group).

## Effect

A changed owner is only written by an UPDATE that is built for another dirty group or for all
columns; changing nothing but the owner leaves the database row unchanged.

## Fix

Set dirty bit 3 when OwnerCharID changes.
