# FW11-027: CSimpleFTP::Connect logs the FTP password

- Original: `CSimpleFTP::Connect` (0x6be610), SR_ShardManager (crest uploader)
- Rewrite: `CSimpleFTP::Connect` in `JMX_ServerFramework/ServerFramework/SimpleFTP.cpp`
- Severity: medium (credentials in log files)

## What the original does

The uploader passes an ftp:// URL that carries user name and password. When `InternetConnectA` fails, the error line "InternetConnect[%s] Failed (%d)" is formatted with the whole URL.

## Effect

The FTP user name and password end up in the engine log whenever the FTP server cannot be reached.

## Fix

Log the host name (`URL_COMPONENTS::lpszHostName`) only.
