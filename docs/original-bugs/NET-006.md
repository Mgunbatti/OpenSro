# NET-006: a session event that cannot be queued is never released

- Original: `Session_PostEvent` 0x492320 (GatewayServer)
- Rewrite: `CSession::PostEvent` in `JMX_Library/BSNet/Session.cpp`
- Severity: minor

## What the original does

The event message is allocated with `AllocMsg`, filled and pushed to the task's queue; the result
of `Push` is ignored.

## Effect

When the queue has been stopped (engine shutdown, `CTaskManager::StopAllQueues`) `Push` fails and
the event message stays allocated: a pool message leaks for every connect, close, handshake or
file event raised in that window.

## Fix

Release the message when `Push` fails.
