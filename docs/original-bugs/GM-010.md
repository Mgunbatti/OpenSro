# GM-010: a shard with user limit 0 divides by zero

- Original: `COverlapJob_RefreshShardStatus::vf01` (0x413560), GlobalManager
- Rewrite: `COverlapJob_RefreshShardStatus::Init` in
  `JMX_CommonServers/GlobalManager/GlobalManagerJobs.cpp`
- Severity: low

## What the original does

Every 10 seconds the job computes the user ratio of every shard as 100 * current users / user limit
(CERT_SHARD +0x224) without checking the limit.

## Effect

A shard configured with the limit 0 makes the main process raise an integer division by zero in its
timer.

## Fix

Use ratio 0 (or 100) when the limit is 0.
