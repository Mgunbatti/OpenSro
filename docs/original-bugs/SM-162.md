# SM-162: Battle arena check answer is not range checked

- Original: `CBattleArenaMgr::OnCheckAndGoAck` (0x670ff0) and `CBattleArenaMgr::StartGame`
  (0x6722c0), SR_ShardManager
- Rewrite: the same functions in `SilkroadOnline/Server/ShardManager/BattleArena.cpp`
- Severity: major

## What the original does

The 0xB4D1 answer of a game server carries the arena kind (0..3) and the match type (0..2).
Neither is checked: the outstanding answer count is read at `+0x2C0 + 4 * (kind * 3 + match)`,
and when that dword is 0 `StartGame` runs, broadcasts 0x34D2 {4, kind, match} and clears the
byte `+0x334 + kind`.

## Effect

A kind of 4 or more (or a match type of 3 or more) reads the count from the following members
or from memory behind the manager; when that value is 0 a game start is announced for an
invalid kind and a byte behind the manager object is overwritten. The rewrite indexes the same
way.

## Fix

Ignore answers with a kind above 3 or a match type above 2.
