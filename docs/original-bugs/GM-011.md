# GM-011: the patch preparation answer is lost when no version is found

- Original: `COverlapJob_PreparePatch::vf06` (0x427fa0) and vf08 (0x428210), GlobalManager
- Rewrite: `COverlapJob_PreparePatch::Execute` / `OnFail` in
  `JMX_CommonServers/GlobalManager/ServiceManagerJobs.cpp`
- Severity: low

## What the original does

When `_ModuleVersion` has no valid row for the module, Execute logs "can't find any version info
..." and fails without freeing the massive reply prepared by the setup. OnFail allocates a new reply
{2, 3} and overwrites the pointer.

## Effect

Every preparation of a module without version leaks one massive message (and its parts) from the
pool.

## Fix

Free the reply before failing, as the other failure paths do.
