# GW-002: one shard without AgentServer ends the shard map build

- Original: `ShardService_BuildMap` (0x412550), GatewayServer
- Rewrite: `ShardService_BuildMap` in `JMX_CommonServers/GatewayServer/ShardConditionManager.cpp`
- Severity: medium

## What the original does

The shard map is built from the certified shard list in order. When a shard has no body of
module "AgentServer", the function frees the new entry, logs "there is unfurnished shard does
not have any agent server : %d - %s" and returns false. `CGatewayServer::OnLocalDataInitialized`
ignores the result.

## Effect

The shards after the one without AgentServer are never offered to clients (they are missing from
0xA101 and logins to them find no shard entry), and `ShardMap_RecomputeReadyFlags` is not run,
so the ready flags of the shards already added keep their certified values until a body changes
its state. The start-up still reports success.

## Fix

Skip the shard (continue with the next one) and compute the ready flags at the end.
