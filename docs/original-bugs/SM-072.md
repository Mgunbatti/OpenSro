# SM-072: A gacha item set row with an unknown object crashes the reader

- Original: `RefGachaItemSet::Read` (0x497980), SR_ShardManager
- Rewrite: `RefRow_Read(CRefRow&, RefGachaItemSetRow&)` in `SilkroadOnline/Server/ServerCommon/RefDataGacha.cpp`
- Severity: minor (with broken data only)

## What the original does

The reader looks up the row's object in the object table and asserts when there is none, then
goes on to compare the count with the object's MaxStack (+0x198) through the NULL pointer.

## Effect

An unknown RefItemID in _RefGachaItemSet makes the server fault while the reference data is
built. The rewrite asserts and drops the row instead (the crash is not reproduced).

## Fix

Drop the row (return 0) after the assert.
