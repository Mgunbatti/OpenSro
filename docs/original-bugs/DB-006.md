# DB-006: Unknown parameter type returns success without executing

- Original: `CDatabase_ExecDirectWithParams` (0x477d60), GatewayServer
- Rewrite: `CDatabase::ExecDirectWithParams` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: wrong

## What the original does

The parameters are bound in a `switch` over the element type (0..5). The `default` case jumps
to the end of the function, past `SQLExecDirect`, with the result still 0.

## Effect

A parameter list with a type other than 0..5 makes the function free the statement and return
0 (`SQL_SUCCESS`) without executing the statement or logging anything; the caller believes the
statement ran.

## Fix

Return an error (and log it) for an unknown type.
