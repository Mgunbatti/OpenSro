# NET-005: NetEngine_Log crashes when there is no engine

- Original: `NetEngine_Log` 0x481ce0 (GatewayServer)
- Rewrite: `NetEngineLog` in `JMX_Library/BSNet/NetEngineLog.cpp`
- Severity: crash

## What the original does

The log function reads the callback at `+0x24` of the engine pointer `0x4FAD50` without checking
the pointer.

## Effect

Any log line written before the engine is constructed or after `Shutdown` (which clears the
pointer) reads address 0x24 and takes the process down. Many low-level helpers log (pools, the
thread manager, the file system, sockets), so for example a socket or pool error reported while
the server shuts down is fatal.

## Fix

Return when `g_pNetEngine` is NULL.
