# GM-016: the billing server address is copied with a limit of 256 characters

- Original: `CBaseBillingMgr::vf00` (0x451390, Initialize), GlobalManager
- Rewrite: `CBaseBillingMgr::Initialize` in
  `JMX_CommonServers/GlobalManager/Billing/BaseBillingMgr.cpp`
- Severity: low

## What the original does

The address argument is copied with `StringCchCopyA(m_szAddress, 256, ...)` into a 16-byte field
(+0x80030); the port follows at +0x80040, then the rest of the object (0x80050 bytes).

## Effect

An address of 16 or more characters overwrites the port (which is stored right after the copy),
the following fields and, from 32 characters on, the heap behind the object. The main process
reads the address from `_billing.ini` into a 16-byte buffer, so it never passes more than 15
characters.

## Fix

Copy with the size of the field (or make the field 256 bytes).
