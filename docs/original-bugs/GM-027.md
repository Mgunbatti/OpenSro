# GM-027: the billing message of 0x620C is leaked for an unknown shard

- Original: `CGlobalManagerMainProcess::vf55` (0x40dcc0), GlobalManager
- Rewrite: `CGlobalManagerMainProcess::OnMsg_620C` in
  `JMX_CommonServers/GlobalManager/GlobalManagerMainProcess.cpp`
- Severity: low

## What the original does

The handler of the shard's user list (0x620C, massive) first allocates an engine message 0x620C
for the billing manager, then looks the shard up. When the shard is not in the certification
data it logs the source position and answers 0xA20C, but the billing message is neither passed
to the billing manager nor released.

## Effect

Every 0x620C of an unknown shard loses one message of the engine's pool.

## Fix

Release the billing message on that path (or allocate it after the lookup).
