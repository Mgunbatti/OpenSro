# SM-041: An object item row that is missing crashes the reader

- Original: `RefObjItem::vf01` (0x48fa80), SR_ShardManager
- Rewrite: `RefObjItem::Read` in `SilkroadOnline/Server/ServerCommon/RefDataObj.cpp`
- Severity: major

## What the original does

The reader looks up the `_RefObjItem` row of the object's Link. When there is none it logs
"Can't find associated item data ..." and asserts, then goes on reading the item columns from
the NULL row.

## Effect

A `_RefObjCommon` item whose Link has no `_RefObjItem` row makes the server crash while it loads
the reference data. The rewrite does the same: after the assert it reads the first item column
from the NULL row.

## Fix

Return 0 for such a row so that the object is dropped, as the character reader does.
