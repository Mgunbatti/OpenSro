# SM-161: Flag world level request keeps the JID of a participant who went offline

- Original: `CFlagWorldMgr::RequestParticipantLevels` (0x66ab50), SR_ShardManager
- Rewrite: `CFlagWorldMgr::RequestParticipantLevels` in `SilkroadOnline/Server/ShardManager/FlagWorld.cpp`
- Severity: minor

## What the original does

The JIDs of the online participants are collected first, then written into 0x74B7 messages of
up to 100 entries. The JID is written before the user is looked up again; a participant who went
offline in between stays in the message without being counted. When he is the last one, the
current message is neither queued nor released and the function asserts.

## Effect

The game servers get JIDs they do not know, and in the last-entry case the message is lost (the
JIDs written into it are never asked for) and a message of the pool leaks. The rewrite does the
same.

## Fix

Look the user up before writing the JID, and queue the message whenever the list is empty.
