# SM-061: The ranking table rows are never freed

- Original: `CRefInstanceGenerator::LoadRankingActivity` (0x4a9f80) and
  `CRefInstanceGenerator::LoadRankingContribution` (0x4aa010), SR_ShardManager
- Rewrite: `RefData_LoadRankingActivity` / `RefData_LoadRankingContribution` in
  `SilkroadOnline/Server/ServerCommon/RefDataQuest.cpp`
- Severity: minor

## What the original does

Each of the six ranking tables is read into a map on the stack (rank -> allocated row), the
ranking packet of its type is written from the map, and the map is destroyed. The map's
destructor frees only its nodes; the rows (44 or 40 bytes plus the name string) are not freed.

## Effect

Every ranking row leaks once per start-up. The amount is small (the tables hold a few ranks).

## Fix

Delete the rows before the map goes, or keep them by value.
