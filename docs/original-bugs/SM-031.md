# SM-031: A _RefMonster_AssignedItemRndDrop row out of service fails the reference build

- Original: `CRefInstanceGenerator::LoadMonsterAssignedItemRndDrop` (0x4a58e0) with
  `RefMonsterAssignedItemRndDrop::Read` (0x4927a0), SR_ShardManager
- Rewrite: `RefDrop_LoadMonsterAssignedItemRndDrop` in
  `SilkroadOnline/Server/ServerCommon/RefDataDrop.cpp`
- Severity: major

## What the original does

The reader returns the monster ID, or 0 for a row out of service (and for the rows it rejects
with a message box). The loader looks the returned ID up as a monster; for 0 there is none, so it
frees the row, asserts and returns FALSE, which stops `BuildAllTables` with "failed to build
reference data".

## Effect

Switching one row of `_RefMonster_AssignedItemRndDrop` off (Service = 0) keeps the shard manager
from starting.

## Fix

Free the row and go on when the reader returns 0.
