# SM-243: Party matching answer crashes when both users are gone

- Original: `CPartyManager::OnPartyMatchJoinAnswer` (0x44fbe0), SR_ShardManager
- Rewrite: `CPartyManager::OnPartyMatchJoinAnswer` in `SilkroadOnline/Server/ShardManager/PartyManager.cpp`
- Severity: major

## What the original does

On an accepted answer the requester and the entry master are looked up by JID. A missing
requester is reported to the master only when the master is there; the next check (master
missing) then reports to the requester and reads its JID and session without checking that the
requester exists.

## Effect

When both users logged out before the answer is processed, the shard manager dereferences a
NULL user and crashes.

## Fix

Return without a notice when neither user is online.
