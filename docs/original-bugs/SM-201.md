# SM-201: The failed hostile-guild withdrawal is logged with a missing argument

- Original: `CGuildManager::OnUnjoinHostileGuild` (0x43ccf0), SR_ShardManager
- Rewrite: `CGuildManager::OnUnjoinHostileGuild` in `SilkroadOnline/Server/ShardManager/Guild.cpp`
- Severity: cosmetic

## What the original does

When `DBEndGuildWar` fails for a war ended through the guild job of the hostile guild request,
it asserts and logs "UNJOIN_HOSTILE_GUILD ERROR[%d]!!! GUILDWARID[%d] RequestorGuildID[%d] "
with only two arguments pushed: the war ID and the guild ID.

## Effect

ERROR shows the war ID, GUILDWARID the guild ID and RequestorGuildID whatever value follows on
the stack. The error code of `DBEndGuildWar` is never logged.

## Fix

Pass the error code, the war ID and the guild ID.
