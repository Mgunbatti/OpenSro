# FW11-022: CSchedule_Everymonths_Date stores the type of Everyweeks_Dayofweek

- Original: `NewSchedule::CSchedule_Everymonths_Date::CSchedule_Everymonths_Date` (0x6d6f90), SR_ShardManager (August 2011 library)
- Rewrite: `CSchedule_Everymonths_Date::CSchedule_Everymonths_Date` in `JMX_Library/BSLib/NewSchedule/Schedule.cpp`
- Severity: none seen (no SR_ShardManager code reads `ISchedule::m_nType`)

## What the original does

Every rule constructor writes its type into `m_nType` (+4): 1 for Everydays up to 10 for Once_Date. The constructor of the "day of every month" rule (type 6) writes 3, the type of Everyweeks_Dayofweek.

## Effect

Code that tells the rules apart by `m_nType` takes a monthly date rule for a weekly one. The schedule row keeps the right type in `m_Data.nType`.

## Fix

Write `SCHEDULE_TYPE_EVERYMONTHS_DATE` (6).
