# SM-021: Every _RefPricePolicyOfItem row leaks

- Original: `CRefInstanceGenerator::LoadPackageItemTables` (0x4a31a0), case 2, SR_ShardManager
- Rewrite: `RefShop_LoadPackageItemTables` in `SilkroadOnline/Server/ServerCommon/RefDataShop.cpp`
- Severity: minor

## What the original does

The loader allocates a 152-byte row and reads it. A row the reader rejects (out of service or of
an unknown package item) is dropped without being freed; an accepted row only hands its price to
`RefPackageItem::ValidateCost` and is then dropped as well. The row is stored nowhere.

## Effect

Each row of the table leaks once per start-up (152 bytes plus its four parameter strings).

## Fix

Read the row into a local object (or free it after `ValidateCost` and on rejection).
