# DB-007: SQLMoreResults loop never ends on an error

- Original: `CDatabase_ExecDirectWithParams` (0x477d60), GatewayServer
- Rewrite: `CDatabase::ExecDirectWithParams` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: crash

## What the original does

With a non-empty parameter list and a successful `SQLExecDirect` the function skips the
remaining results with `while (SQLMoreResults(h) != SQL_NO_DATA);`.

## Effect

If `SQLMoreResults` reports `SQL_ERROR` (a later statement of a batch or procedure fails, the
connection drops) or `SQL_INVALID_HANDLE`, it keeps returning that value and the calling thread
spins forever.

## Fix

Stop on any result other than `SQL_SUCCESS` / `SQL_SUCCESS_WITH_INFO` and report the error.
