# NET-009: CreateNewSession loses the session when no ID is left

- Original: `SessionTable_CreateNewSession` 0x4945e0 (GatewayServer)
- Rewrite: `CSessionTable::CreateNewSession` in `JMX_Library/BSNet/SessionTable.cpp`
- Severity: minor

## What the original does

The session is taken from the pool first; when `IdPool_Alloc` then returns 0 the function logs
`CreateNewSession() - ...` and returns 0 without giving the session back.

## Effect

One pooled session per failure stays counted as in use. The ID pool refills itself, so a 0 ID
only appears after the 32-bit counter wrapped; in practice the path is not reached.

## Fix

Return the session to the pool before failing.
