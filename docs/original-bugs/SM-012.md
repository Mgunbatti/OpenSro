# SM-012: A _RefMagicOptAssign row with Race 4 or more writes past the assign tables

- Original: `CRefInstanceGenerator::BuildMagicOptAssignTables` (0x51aa70), SR_ShardManager
- Rewrite: `RefMagicOptTables::BuildMagicOptAssignTables` in `SilkroadOnline/Server/ServerCommon/ReferenceData.cpp`
- Severity: minor

## What the original does

The Race column picks one of the four static `MagOptEachLevelTable` maps (0x89bc80). A Race of 4
or more only asserts; the row is then inserted into "map" number Race, which is memory after
the array.

## Effect

A bad assign row corrupts static data of the shard manager (or crashes it) instead of being
rejected.

## Fix

Skip the row (or fail the build) when Race is not below 4.
