# SM-163: Party arena layer opened before the party members are looked up

- Original: `CBattleArenaMgr::StartGameParty` (0x672d40), SR_ShardManager
- Rewrite: `CBattleArenaMgr::StartGameGroup<DwordMap>` in
  `SilkroadOnline/Server/ShardManager/BattleArena.cpp`
- Severity: minor

## What the original does

For each pair of parties the party version of the team building opens an arena layer, stores it
in the team and announces it with 0x34D2 {6, world, layer, 1, match}. Only then does it look up
the member maps of the two parties (`+0x178`). When either party has no member map, the pair is
skipped. The guild version does the lookup first.

## Effect

The opened layer belongs to no team: the next pair opens another layer over it in the same team
object, so the first layer is never closed by `CloseArenaLayers` and only goes away through the
empty-layer timeout of the game world. The game servers have been told about a layer nobody
enters.

## Fix

Look up both member maps before opening the layer, like the guild version.
