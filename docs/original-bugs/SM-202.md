# SM-202: The GP history clean-up result of a guild load is never checked

- Original: `CGuildCommon::vf01` (0x4401f0), SR_ShardManager
- Rewrite: `CGuildCommon::Initialize` in `SilkroadOnline/Server/ShardManager/GuildCommonShard.cpp`
- Severity: minor

## What the original does

Loading a guild runs `{?=CALL _DeleteGPHistory (%d)}` and is meant to log and fail on the
results -3 ("Failed to delete gp history. Unknown DB Error") and -1 ("Not found guild"). The
result is read with `movzx` from its low byte, so the compared value is 0..255 and never equals
-3 or -1.

## Effect

Both failures go unnoticed: the guild loads its GP history as if the clean-up had worked, and
the two log lines are dead code.

## Fix

Compare the full int result (or sign-extend the byte).
