# GM-006: the punishment query sends one account text twice

- Original: `COverlapJob_QueryPunishment::vf06` (0x4269a0), GlobalManager
- Rewrite: `COverlapJob_QueryPunishment::Execute` in
  `JMX_CommonServers/GlobalManager/ServiceManagerJobs.cpp`
- Severity: low

## What the original does

After `exec _GetUserInfo` the reply gets the JID and five strings of the 128-byte row: the texts at
offsets 0, 0x14, 0x14, 0x2A and 0x3A. The text at 0x14 is written twice and nothing else of the row
between 0x14 and 0x2A is sent.

## Effect

The SMC shows the same value in two fields; whatever the second field should have been is never
sent.

## Fix

Write the intended field (probably a text between 0x14 and 0x2A) instead of the repeat.
