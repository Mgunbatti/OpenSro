# AS-005: the login is checked against an unset address when the peer address is unknown

- Original: `CAgentMainProcess::OnMsg_6103` (0x402120), AgentServer
- Rewrite: `CAgentMainProcess::OnMsg_6103` in `JMX_CommonServers/AgentServer/AgentMainProcess.cpp`
- Severity: low

## What the original does

The handler asks the engine for the client's address (`GetSessionPeerAddress`) without looking at
the result and compares the uninitialised local with the token's address when the call fails (the
session is already gone). The same value is stored in the user and sent to the GlobalManager.

## Effect

For a session that vanished during the login the token check uses stack garbage; normally it then
fails ({2, 1}) and the token is used up.

## Fix

Answer {2, 3} when `GetSessionPeerAddress` fails.
