# DB-010: Columns without a format text crash the describe step

- Original: `CDBTable::DescribeColumns` (0x478e40), GatewayServer
- Rewrite: `CDBTable::DescribeColumns` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: crash

## What the original does

Each described column gets the printf format of its type from `DBColType_GetSqlFormatSpec`
and stores it with `std::string::assign(p, strlen(p))`. For `SQL_FLOAT` (type 5) and every SQL
type the library does not map (decimal, numeric, money, binary, wide char, date, ...) the format
is NULL.

## Effect

`strlen(NULL)` faults: opening a table that contains such a column crashes the process.

## Fix

Reject or skip unsupported columns with an error message.
