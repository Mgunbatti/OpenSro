# MM-001: the PDH query is never closed

- Original: `PerfCounter_CloseAll` (0x421c60), MachineManager
- Rewrite: `PerfCounter_CloseAll` in `JMX_CommonServers/MachineManager/PerfCounter.cpp`
- Severity: low

## What the original does

At shutdown (`CMachineManager::OnShutdown`) the performance counter query is closed with
`PdhCloseQuery`, but the function gets the address of the global query handle instead of the
handle. PDH rejects it as an invalid handle; the global is then set to NULL and the counter
records are freed.

## Effect

The query and its counters stay open until the process ends. Since this only happens at
shutdown, nothing is lost in practice; a module that reinitialised its local data would leak one
query per round.

## Fix

Pass the handle: `PdhCloseQuery(g_hPerfQuery)`.
