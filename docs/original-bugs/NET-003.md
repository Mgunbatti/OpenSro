# NET-003: Connect and AddKeepAliveTarget ignore the bind address

- Original: `CNetEngine::Connect` 0x480820, `CNetEngine::AddKeepAliveTarget` 0x4816a0
  (GatewayServer)
- Rewrite: `CNetEngine::Connect` in `JMX_Library/BSNet/NetEngine.cpp`,
  `CNetEngine::AddKeepAliveTarget` in `JMX_Library/BSNet/KeepAlive.cpp`
- Severity: wrong

## What the original does

Both functions resolve the bind IP string (`ResolveHostIPv4`) and fail when it does not resolve,
but the result is never written anywhere. They zero a second `sockaddr_in` for the bind address,
fill only the destination one and pass the bind block only when its address is non-zero, which
it never is.

## Effect

The local address given to `Connect` / `AddKeepAliveTarget` has no effect; the connection (and
every keep-alive reconnect) uses whatever local address Windows picks. On multi-homed servers
outgoing connections can leave from the wrong interface. Only `ConnectSockAddr` with an explicit
bind address binds.

## Fix

Fill the bind `sockaddr_in` (family, port 0, resolved address) and pass it when an address was
given.
