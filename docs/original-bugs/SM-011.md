# SM-011: A _RefRentItem row out of service stops the reference data build

- Original: `CRefInstanceGenerator::LoadRentItem` (0x4a6d10), SR_ShardManager
- Rewrite: `RefData_LoadRentItem` in `SilkroadOnline/Server/ServerCommon/ReferenceData.cpp`
- Severity: major

## What the original does

`RefRentItem::Read` (0x499240) returns 0 for a row whose Service column is 0. The loader then
returns 0 without freeing the 60-byte row, and the table builder (0x4d0700) treats that as a
broken row: it asserts and reports failure, so `BuildAllTables` shows "failed to build reference
data from this[_RefRentItem] table" and the shard manager does not start.

## Effect

Switching a rent item off in the database (Service = 0) keeps the server from starting; the
row also leaks.

## Fix

Free the row and return 1 for a row out of service, like the other loaders.
