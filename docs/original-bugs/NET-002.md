# NET-002: GetStatistics reports only the accepted socket pool

- Original: `CNetEngine::GetStatistics` 0x481220 (GatewayServer)
- Rewrite: `CNetEngine::GetStatistics` in `JMX_Library/BSNet/NetEngine.cpp`
- Severity: minor

## What the original does

With flag 2 the function reads the counters (capacity, in use, free) of the connecting socket
pool (`+0x118`) and then of the accepted socket pool (`+0x194`) into the same three local
variables, and stores them once.

## Effect

The socket statistics (`+0x14..+0x1C` of the output) always show the accepted socket pool; the
connecting sockets (outgoing connections to other servers) are never reported.

## Fix

Add the two pools' counters, or report them in separate fields.
