# SM-102: A reused game world layer keeps the old create parameter list

- Original: `sGameWorldCreateParam::CopyAssign` (0x65ba00), SR_ShardManager
- Rewrite: `sGameWorldCreateParam::CopyTo` in `SilkroadOnline/Server/ShardManager/GameWorld.cpp`
- Severity: minor

## What the original does

The copy used by `GameWorldLayer::Init` copies the plain fields and then the DWORD vector, but
only when the source vector is not empty. An empty source leaves the destination's vector as it
was.

## Effect

Closed layers go to the world's free list and are reused by the next CreateLayer. When the new
create parameters have no list, the layer keeps the list of its previous instance and sends it
in 0x3C15 (opened) and 0xBC10 (layer list). The rewrite does the same.

## Fix

Assign the vector unconditionally (clear it for an empty source).
