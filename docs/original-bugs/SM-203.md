# SM-203: A guild war start that fails is answered as success or not at all

- Original: `CGuildManager::OnGuildWarBegin` (0x439b00), SR_ShardManager
- Rewrite: `CGuildManager::OnGuildWarBegin` in `SilkroadOnline/Server/ShardManager/Guild.cpp`
- Severity: major

## What the original does

Subtype 50 of 0x78F7 calls `DBBeginGuildWar`. For any result other than 1 and 0x4C0C it logs
"failed to begin guild war!!! [error_code: %d]" and returns without answering. For 0x4C0C (the
procedure reported -2 / -3, no war record kept) it asserts on the missing war, skips the 0x38F5
subtype 25 notification (SendGuildWarBegun asserts on NULL) and answers 0xB8F7 {request ID, 1}.

## Effect

A rejected war is reported to the game server as started, and every other failure (unknown
guild, guilds already hostile, DB error) leaves the request without an answer, so the game
server's pending request never completes.

## Fix

Answer {2, WORD error} for every result other than 1.
