# SM-104: "Already Closed World" logs the packed world and layer as the world ID

- Original: `CGameWorldMgr::OnCloseWorldRequest` (0x65c720), SR_ShardManager
- Rewrite: `CGameWorldMgr::OnCloseWorldRequest` in `SilkroadOnline/Server/ShardManager/GameWorld.cpp`
- Severity: cosmetic

## What the original does

The request carries world and layer ID as one DWORD (world in the low word). When the layer is
already closed the log line passes the whole DWORD for "World ID = %d".

## Effect

The logged world ID is world + layer * 65536. The rewrite does the same.

## Fix

Pass the low word.
