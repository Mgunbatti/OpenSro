# DB-003: SQL diagnostics and query text are used as printf formats

- Original: `CDatabase::HandleSQLError` (0x47b200), GatewayServer
- Rewrite: `CDatabase::HandleSQLError` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: crash

## What the original does

The first log line is written correctly with `NetEngine_Log(0x2000001, "%s", query)`. For
every block of diagnostic records the function then calls `NetEngine_Log(0x2000001, text)` and
`NetEngine_Log(0x2000001, query)`: the collected "SQL Error State:..., ODBC Error: ..." text and
the query text are passed as the format string.

## Effect

A `%` in the failing statement (for example `LIKE 'abc%'`, a percentage, a user supplied
name) or in the driver message is interpreted as a conversion: `%%` loses a character, `%d`
prints stack contents, and `%s` / `%n` read or write through random stack values and can crash
the server while it reports a database error. Every error also logs the query twice.

## Fix

Log both texts with `"%s"`.
