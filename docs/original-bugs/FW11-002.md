# FW11-002: CRegistry::QueryString reads past its buffer

- Original: `CRegistry::QueryString(const char*, std::string*)` (0x4898d0), AgentServer (2011
  library)
- Rewrite: `CRegistry::QueryString` in `JMX_Library/BSLib/Util/Registry.cpp`
- Severity: low (not called in AgentServer)

## What the original does

The value is read into an uninitialised 256-byte buffer with a size of 255 and then assigned
with `strlen`. `RegQueryValueExA` does not add a terminator when the stored value has none, so a
value of exactly 255 bytes without a terminating NUL leaves the buffer unterminated.

## Effect

`strlen` runs past the value into the rest of the stack: the string gets garbage appended, or
the read faults.

## Fix

Set the byte after the returned size to 0 (or zero the buffer first).
