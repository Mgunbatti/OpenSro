# DB-005: Delete by key executes only the WHERE clause

- Original: `CDBTable_ExecFormattedNoResult` (0x4786e0), GatewayServer
- Rewrite: `CDBTable::DeleteByKey` in `JMX_Library/BSLib/DB/Database.cpp`
- Severity: wrong

## What the original does

The function formats the key clause ("WHERE id=%d" with the caller's values) into a 3 KB
buffer, then builds `m_strDelete + " " + clause` ("DELETE FROM t WHERE id=5") in a
`std::string`. The statement passed to `CDatabase_ExecDirectNoResult` is the formatted buffer,
not the built string.

## Effect

The driver receives "WHERE id=5" alone, rejects it as a syntax error, and the function returns
`SQL_ERROR`; nothing is ever deleted through this function. The Gateway does not call it.

## Fix

Execute the concatenated statement.
