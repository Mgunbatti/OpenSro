# GM-022: the IP statistics count every row for an empty country code

- Original: `sub_45D850` (0x45d850, CGlobalManagerSlave, row trigger of `exec _IPStatistics`),
  GlobalManager
- Rewrite: `CGlobalManagerSlave::OnIPStatisticsRow` in
  `JMX_CommonServers/GlobalManager/GlobalManagerSlave.cpp`
- Severity: medium

## What the original does

For each row the address is looked up in the IP country table into a local 4-byte code. The map
of the statistics is then searched and filled with a `std::string` that was cleared before the
lookup and is never assigned the code; the new entry's code is copied from the same empty
string.

## Effect

The statistics always have a single entry with the empty code and the number of rows. The
0xA319 answer lists one country with the name of the empty code ("**" unless the country code
file has a line without a tab) instead of the counts per country.

## Fix

Assign the looked-up code to the string before searching the map.
