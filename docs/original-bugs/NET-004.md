# NET-004: GetSessionLocalMacAddress allocates 640 times the adapter list size

- Original: `CNetEngine::GetSessionLocalMacAddress` 0x481e60 (GatewayServer)
- Rewrite: `CNetEngine::GetSessionLocalMacAddress` in `JMX_Library/BSNet/NetEngine.cpp`
- Severity: minor

## What the original does

`GetAdaptersInfo(NULL, &size)` returns the needed size in bytes. The function then allocates
`new IP_ADAPTER_INFO[size]`, i.e. `size` adapter records of 640 bytes each.

## Effect

A temporary allocation 640 times larger than needed on every call (several MB with a few
adapters). It is freed again before returning, so nothing leaks.

## Fix

Allocate `size` bytes.
