# GW-006: notice count of 0xA104 wraps at 256

- Original: `CArticleManager::WriteArticles` (0x4013e0), GatewayServer
- Rewrite: `CArticleManager::WriteArticles` in `JMX_CommonServers/GatewayServer/ArticleManager.cpp`
- Severity: minor

## What the original does

The articles of the requested type are counted in a BYTE register, the BYTE is written as the
count of 0xA104, and then every matching article is written.

## Effect

With more than 255 articles of one type the count wraps (256 articles are announced as 0) while
all of them follow, so the client reads the rest of the message wrongly.

## Fix

Stop writing after 255 articles, or count in a wider type and limit the list.
