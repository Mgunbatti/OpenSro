# SM-005: An item with more than 12 magic parameters overruns the parameter array

- Original: `CInstanceItem::CopyTo` (0x5220c0), `CInstanceItem::Write` (0x522490),
  `CInstanceItem::Read` (0x522930), SR_ShardManager
- Rewrite: `CInstanceItem::CopyTo` / `Write` / `WriteMagParams` / `Read` in
  `SilkroadOnline/Server/ServerCommon/InstanceRecords.cpp`
- Severity: crash

## What the original does

`_ITEMS` has twelve `MagParam` columns (`MagParam[12]` at +0x60) and a `MagParamNum` byte.
Every loop over the parameters runs `MagParamNum` times; a count above 12 only triggers an
assert (CopyTo per index, Write / Read once before the loop) and the loop goes on.

## Effect

With `MagParamNum` 13..255 (a bad database row or stream), Write sends whatever follows the
array (`Serial64`, the binding option map, the rent info pointer, the next heap block), CopyTo
writes the following members of the destination record and Read overwrites them from the
stream, up to 1.9 KB past the array: heap corruption and a crash.

## Fix

Clamp the count to 12 (or reject the row) before the loops.
