# SM-273: A failed accepted mentor application keeps the recruit entry locked

- Original: `CTrainingCampManager::ProcessMentorJob` (0x459b30), SR_ShardManager
- Rewrite: `CTrainingCampManager::ProcessMentorJob` in `SilkroadOnline/Server/ShardManager/TrainingCamp.cpp`
- Severity: minor

## What the original does

`TrainingCamp_HandleReq7C00_ApplyToRecruit` sets the pending flag (+0x34) of the recruit entry
before the leader is asked. A refusal or a timeout clears it, and so does a successful accept.
When an accepted answer fails (the entry is gone, the leader has no camp any more or
`AddMember` fails) both users get the error notice and the flag stays set.

## Effect

Every further application to that entry is answered with 0x6827 (pending) until the leader
removes and registers the entry again.

## Fix

Clear `m_bPending` on every return path once the entry was found.
