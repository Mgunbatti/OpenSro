# AS-003: the byte count of 0x2209 is read from a released message

- Original: `CAgentMainProcess::OnMsg_2209` (0x4032c0), AgentServer
- Rewrite: `CAgentMainProcess::OnMsg_2209` in `JMX_CommonServers/AgentServer/AgentMainProcess.cpp`
- Severity: low

## What the original does

The handler copies the data into a new message, sends it to the client and releases it, and only
then reads that message's size field to add it to the "MsgSentBytes" counter of the monitor
graph.

## Effect

When the send already completed the message is back in the pool (and may be in use by another
thread), so the counter can add the size of an unrelated message.

## Fix

Take the size before `ReleaseMsg`.
