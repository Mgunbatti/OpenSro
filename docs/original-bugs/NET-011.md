# NET-011: accepted sessions are announced before the peer address is known

- Original: `CSockListener_CreateSessionForAccepted` 0x470990 (GatewayServer)
- Rewrite: `CSockListener::CreateSessionForAccepted` in `JMX_Library/BSNet/SockListener.cpp`
- Severity: wrong

## What the original does

For a completed `AcceptEx` the listener first calls `CreateNewSession` (which links the session,
posts the connect event 0x1001 to the application and starts receiving) and only afterwards
`AcceptPeer`, which reads the peer address from the `AcceptEx` buffer and checks the connect
time.

## Effect

An application thread that handles the connect event and asks for the peer address
(`GetSessionPeerAddress`) can get 0.0.0.0:0, or the previous peer's address for a recycled
socket. A connection dropped by the connect time check has already been announced.

## Fix

Call `AcceptPeer` before creating the session.
