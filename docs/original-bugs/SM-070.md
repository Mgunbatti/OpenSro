# SM-070: The "already has this index" line of the collection book has three %s and two arguments

- Original: `CRefInstanceGenerator::ValidateCollectionBook` (0x4add80), SR_ShardManager
- Rewrite: `RefData_ValidateCollectionBook` in `SilkroadOnline/Server/ServerCommon/RefDataMisc.cpp`
- Severity: minor

## What the original does

When two _RefCollectionBook_Item rows name the same SlotIndex of one theme, the validation logs
"Theme '%s' already has this index. ItemCodeName : %s  ThemeCodeName : %s". It pushes only the
item code name and the theme code name, so the first `%s` (meant for the theme) shows the item,
the second the theme, and the third reads whatever lies on the stack above the arguments.

## Effect

The log line is misleading, and the third `%s` may print garbage or fault on an invalid pointer
when the data is wrong. The rewrite keeps the order of the two arguments and passes an empty
string for the third (the stack contents of the original cannot be reproduced).

## Fix

Pass the theme code name, the item code name and the theme code name again, in that order.
